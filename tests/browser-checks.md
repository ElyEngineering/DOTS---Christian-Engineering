# Browser acceptance checks

Use representative widths 1440, 1024, 768, 390, and 320 px. Also test 200% zoom or enlarged text.

1. Page and assets load, with no console errors or horizontal overflow.
2. Hero text remains legible against landscape; tagline and Ephesians 5:25 fit without clipping.
3. All of Ephesians 5:21–33 is visible in normal page flow, without any disclosure controls.
4. Desktop navigation goes to the correct section and preserves usable Back/Forward navigation.
5. On phone, Menu opens. Tab/Shift+Tab stay within the native dialog; Escape and Close dismiss it. Repeat opening and closing. Section navigation closes the dialog and moves focus to the destination. Resize from open mobile menu to desktop.
6. Call/text/email links target the published number/address; do not send test messages.
7. External attraction links go to their official destinations and disclose new-tab behavior.
8. Reduced-motion mode removes animation and smooth scrolling. All content is visible if JavaScript is disabled.
9. Reading progress updates without moving the page. No autoplay media or continuous decorative animation is present.
10. Print view includes the complete Scripture passage and contact number; no overlap or dark full-page blocks.
11. Landscape captions do not identify regional imagery as community property; planned features remain plainly labeled.
